Defect and scoped correction
  - Account-sync failures at 12:52:11, 13:50:07 and 14:05:07 reported
    "already have such name (/queue/simple/add; line 67)". Each next pass
    recovered. One separate 25-second sync timeout at 14:32 also recovered.
  - Login/logout hooks, the account sync, and the congestion controller can
    call nister-qos-devices concurrently. Two snapshots can both see a missing
    leaf and then try to create the same name.
  - The device reconciler now permits one named native script job to perform
    writes at a time. Overlapping calls skip the body and allow their caller
    to continue normally. No persistent global lock can remain after a crash.
  - The controller reads all account telemetry in one table snapshot, replacing
    three individual CLI reads per account. This also avoids reading stale
    queue IDs after concurrent removal. Native rate arrays retain both
    upload/download values and account CIRs in the existing wire format.
  - Deployed only the device script source and controller Python source. No
    plan rates, account access states, radio settings, credentials, firewall,
    VPN, captive pages or payment routing were changed by this correction.
